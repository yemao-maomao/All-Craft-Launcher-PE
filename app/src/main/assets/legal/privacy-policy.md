## 1. 引言

1.1 本隐私政策说明 ACL-PE 在你使用本应用时**如何收集、使用、存储、共享与保护信息**，以及你对自己信息享有的选择与控制。我们尊重并保护你的隐私，本应用遵循"**本地优先、最小必要、明示同意、可拒绝可撤销**"的设计原则。

1.2 本应用是一款**开源的第三方 Minecraft Java 版启动器**（Android 端，仅 arm64-v8a）。我们**不是** Mojang Studios、Microsoft、Minecraft 官方或任何官方授权的关联方；本应用不打包、不分发 Minecraft 游戏本体（游戏 jar、资源文件、依赖库均在你设备上从官方或第三方镜像源获取）。

1.3 **核心结论（先读这段）**：

- 本应用**不设账号体系**（无注册、无登录、无云端账户），我们**不运营任何收集你个人信息的服务器**；我们不收集你的姓名、手机号、身份证件、通讯录、位置、短信、通话记录、相册或已安装应用列表。
- 你创建的启动器账户（离线账户或未来的微软账户凭据）**仅保存在你的设备上**，其中凭据类数据经 Android Keystore 加密存储。
- 诊断日志**默认关闭**，只有在你在设置中主动开启"开发者模式"后才会记录更详尽的技术日志，且日志始终保存在你设备的应用私有目录内。
- 本应用**不申请麦克风权限**，不使用麦克风；**不读取任何物理传感器数据**用于识别或追踪你。
- 只有当你在应用内主动触发联网功能（下载运行环境、下载游戏版本、搜索与下载社区资源、访问第三方认证/服务）时，才会与**你指定的第三方服务**发生网络传输；传输内容与你所执行的操作一一对应。

1.4 本政策与《ACL-PE 用户协议》共同构成你与我们之间关于本应用的完整约定。若你不同意本政策任何内容，请勿安装或使用本应用；已安装的，请立即卸载并删除应用数据。

## 2. 在设备上储存和处理信息

2.1 **存储位置与性质**。本应用的全部业务数据均存储在你设备的**应用私有目录**中（Android 标准路径：`/data/data/org.aclpe.aclpe/`，对应应用内 `files/` 目录）。此目录受 Android 系统沙箱保护，其他应用在正常情况下无法访问。你主动选择导出（如导出 `options.txt`、导出日志）时，文件才会离开该目录，去向由你决定。

2.2 **在设备上储存的主要信息类别**：

| 类别 | 具体内容 | 位置（应用私有目录内） | 用途 |
|---|---|---|---|
| 运行环境 | 内置 JRE 运行时解压产物、就绪标记（`.build`） | `files/env/jre/<版本>/arm64/`、`files/env/.assets/` | 让启动器拥有可运行游戏的 Java 环境 |
| 游戏版本 | 版本元数据 json、客户端 jar、依赖库、assets 资源、natives 解压产物 | `files/runtimes/<配置名>/`（`versions/`、`libraries/`、`assets/`、`natives/`） | 安装与启动你选择的游戏版本 |
| 游戏配置 | 游戏 `options.txt` 与其备份 `options.txt.bak` | `files/runtimes/<配置名>/options.txt` | 让你在启动器内编辑游戏选项，支持回退 |
| 启动器设置 | 主题、仅 Wi-Fi 下载、崩溃捕获开关、**开发者模式开关**、内存档位、镜像源、图形后端、性能开关、法务文档同意记录（版本号与时间戳） | DataStore（`files/datastore/`）与 `runtimes/<配置名>/settings/` | 记住你的偏好与同意状态 |
| 账户数据 | 离线账户（昵称、本机生成的 UUID）；未来可选微软账户的令牌 | `files/accounts/`（令牌为 `tokens.enc`） | 让你以某个身份进入游戏与联机 |
| 日志 | 运行日志、可选崩溃日志 | `files/logs/launcher.log` 及轮转文件 | 排障与技术改进（见第 4 节） |
| 皮肤缓存 | 你账户的皮肤图片与 ETag | `files/cache/skins/` | 避免重复下载皮肤 |
| 触控方案 | 你保存的虚拟按键映射方案 | `runtimes/<配置名>/touch/` | 记住你的操作布局 |
| 导出文件 | 你主动导出的配置（如 `options.txt`）、导入源文件 | `files/exports/` | 配置迁移 |

2.3 **处理方式**。上述信息全部**在你的设备本地生成与处理**，我们**不在服务器端接收、汇总或分析**它们。本应用可能在你操作时进行必要的本地计算（如校验文件完整性、解压压缩包、生成启动参数、解析选项文件），这些计算均在你的设备上完成。

2.4 **保存期限与删除**。本地数据**不设固定保存期限**，由你控制：

- 在 Android 系统"设置 → 应用 → ACL-PE → 存储"中清除数据，或在应用内删除对应配置/账户，即可删除相应信息；
- 卸载本应用会删除应用私有目录下的全部数据（Android 系统保证）；
- 你主动导出到共享目录（如 `/sdcard/`）的文件不会随卸载删除，需你自行清理。

2.5 **权限与访问范围**。本应用遵循最小权限原则，仅申请以下权限，且均有明确用途：

- `INTERNET`：联网下载（运行环境、游戏版本、社区资源、第三方认证）；
- `ACCESS_NETWORK_STATE`：判断当前是否 Wi-Fi，用于"仅 Wi-Fi 下载"策略。

**本应用不申请**：麦克风、摄像头、位置、通讯录、短信、通话、日历、身体传感器、后台读取应用列表等权限；应用清单中若保留"所有文件访问"（MANAGE_EXTERNAL_STORAGE）声明，该权限**不会在默认流程中请求**，仅在你主动使用导入/导出类功能且系统要求时，才由你决定是否授予；拒绝不影响启动器核心功能（可使用应用私有目录）。

## 3. 账户信息

3.1 **本应用不运营账户服务器，也不要求你注册**。所谓"账户"指你在本机创建、用于进入游戏的**本地身份**：

3.2 **离线账户（本机账户）**：

- 你在应用内创建的离线账户包含：**昵称**（你自行输入）与**本机随机生成的 UUID**；
- 该信息保存于 `files/accounts/`，**仅用于单机游戏内的身份标识**，不上传给我们，也不会自动发送给任何第三方；
- 离线账户的**限制**（应用内亦有明确提示）：无皮肤同步、无法通过官方认证服务器联机（无法进入需要正版验证的服务器）、部分服务器会拒绝连接、可能违反 Minecraft 官方最终用户许可协议（EULA）；**仅供单机体验，我们不将其作为默认推荐**。

3.3 **微软账户（可选，本期仅预留接口与流程，尚未启用）**：

- 未来启用时，登录将通过**微软官方 OAuth 2.0 授权码 + PKCE 流程**在系统浏览器（Custom Tabs）中完成；我们**不接触、不索要、不存储你的微软账号密码**；
- 授权后由微软返回的**访问令牌/刷新令牌**将保存在你设备上，并以 **Android Keystore（AES-GCM）** 加密存储（`files/accounts/<账户>/tokens.enc`）；
- 令牌仅用于：向微软/Xbox Live 服务换取游戏所需的认证凭据、查询你的公开游戏档案（名称、UUID、皮肤地址）。令牌不会被上传到我们的服务器，也不会用于其他目的；
- 你可随时在应用内退出登录：本应用会删除本地令牌与其账户记录；如需彻底撤销授权，你还可前往微软账户管理页面撤销应用授权。

3.4 **我们如何处理（以及不处理）账户相关信息**：

- 我们不建立云端账户画像、不做跨设备同步、不做身份关联分析、不向第三方出售或共享账户信息；
- 日志脱敏门面会对访问令牌、刷新令牌、JWT 等敏感形态做**脱敏处理**后才允许写入日志文件；
- 你应妥善保管设备与解锁凭据；设备被他人物理使用可能导致本地账户被使用，这属于设备安全范畴，我们无法代为防护。

3.5 **未成年人**。若你是未成年人，请在父母或其他法定监护人同意并指导下创建账户与使用本应用；我们不会针对未成年人收集额外信息。

## 4. 诊断信息与日志

4.1 **默认状态：崩溃捕获默认关闭，详尽日志默认关闭**。这意味着在默认配置下，本应用**只记录维持基本运行所必需的常规日志**（启动、版本、关键流程结果等），且这些日志**始终仅保存在你的设备上**。

4.2 **开发者模式（你在设置中主动开启）**：

- 开启后，本应用会记录更详尽的**技术日志**，用于定位问题，包括：环境探测过程与结果、下载/校验/解压各阶段进度与耗时、任务状态流转、错误码、文件路径、设备与系统的基本技术信息（Android 版本、ABI、内存档位）；
- 上述日志写入 `files/logs/launcher.log`（含大小轮转，历史文件为 `.1`/`.2`/`.3`），**不会自动上传**；
- 日志中**不会**包含你的密码、微软令牌明文、身份凭证；对可能出现的敏感串，写盘前统一经过脱敏门面处理；
- 你可随时在设置中关闭开发者模式，恢复为常规日志级别。

4.3 **崩溃捕获（你在设置中主动开启）**：

- 开启后，应用崩溃时会在 `files/logs/` 下生成崩溃记录文件，内容为崩溃时的调用栈与少量运行上下文，用于你自行排障**或将文件主动提供给我们**（例如通过邮件或 Issue 反馈）；
- 关闭状态下不会生成此类文件。

4.4 **你主动分享日志时请注意**：日志可能包含设备型号、系统版本、文件路径与账户**昵称**等技术信息。请在你完全知情、并自行判断风险后再分享；你有权在分享前自行编辑删除任何部分。我们仅会将你主动提供的日志用于**定位与你所报问题相关的技术缺陷**。

4.5 **我们不做的事**：不采集广告标识、不做行为埋点、不接入第三方统计/广告/推送 SDK、不进行用户画像、不将日志用于任何形式的商业分析。

## 5. 麦克风与传感器

5.1 **麦克风**：本应用**不申请麦克风权限，不录制、不采集、不处理任何音频**。若未来某个可选功能（例如语音相关扩展）需要麦克风，我们会在使用前**单独、明确地**征求你的授权，并同步更新本政策；未获授权时该功能不可用，且不影响启动器的其他功能。

5.2 **物理传感器**：本应用**不读取加速度计、陀螺仪、磁力计、气压计、光线/距离传感器等物理传感器数据**用于识别、追踪或画像。

5.3 **输入事件**：本应用在游戏运行时接收触摸输入（触屏位置、手势、虚拟按键映射），目的是**将你的操作转达给游戏进程**。这些输入事件在设备本地处理，不持久化，不上传。

5.4 **用户主动提供的媒体**：你可以在应用内选择文件（例如用于预览或作为配置导入源）。这些文件仅在你主动选择时被读取，用于你所指定的功能；我们不会在后台扫描你的存储。

## 6. 联网功能涉及的信息传输

6.1 本应用**不主动联网**。只有在**你触发**以下操作时才会发起网络请求，且请求目标为**相应服务的提供方**（不是我们）：

| 你触发的操作 | 请求目标（示例） | 传输内容 | 目的 |
|---|---|---|---|
| 获取版本清单 | `piston-meta.mojang.com`、镜像 `bmclapi2.bangbang93.com` | 请求的清单文件名、请求头（含本应用名称/版本的 User-Agent） | 列出可供安装的游戏版本 |
| 下载版本文件（json/jar/库/assets） | Mojang 官方下载域、BMCLAPI 镜像 | 文件路径、范围请求（Range，用于断点续传）、User-Agent | 安装你所选版本 |
| 拉取运行环境 | 内置资产（APK 内，不走网络）；或在无内置资产时由镜像站提供 | 请求的文件名、User-Agent；校验用哈希仅在本机比对 | 补齐 Java 运行环境 |
| 搜索/浏览社区资源 | `api.modrinth.com` | 搜索关键词、筛选条件、User-Agent | 展示模组等社区内容元数据 |
| 下载社区资源（后续功能） | Modrinth 内容分发域 | 文件地址、Range、User-Agent | 下载你选择的资源 |
| 微软登录（未来启用） | 微软登录、Xbox Live、Minecraft 服务接口 | OAuth 授权码/令牌交换所需参数、你的 Xbox/Minecraft 公开档案请求 | 完成认证与获取皮肤地址 |
| 获取皮肤 | 皮肤纹理服务域（https） | 你的皮肤哈希、ETag（用于缓存校验） | 显示或缓存皮肤 |
| 检查应用更新（如启用） | 我们指定的发布页/仓库地址 | 当前版本号、User-Agent | 提示是否有新版本 |

6.2 **共同的技术性信息**：任何网络请求都不可避免地会向**目标服务器**暴露发起方的 IP 地址、发起时间、请求内容与客户端标识（User-Agent）。这是互联网协议的基本特性，由**目标服务的隐私政策**约束，我们无法控制第三方如何记录与使用这些信息。我们建议你阅读相应服务的隐私政策（例如 Mojang/Microsoft 的隐私声明、Modrinth 的隐私政策）。

6.3 **明文传输的例外与风险控制**：本应用默认仅允许 HTTPS（网络安全配置默认禁止明文）。当前唯一允许明文的域名是社区运行环境镜像 `oss.mcddos.top`（该镜像仅提供 HTTP 端点）。为控制风险：我们对该镜像下载物使用**应用内置的 SHA-256 校验值**进行完整性校验，校验失败即拒绝安装并报错。若你对此不接受，可仅使用 APK 内置的运行时（不触发该域名请求）。相关配置位于应用内 `res/xml/network_security_config.xml`，可审计。

6.4 **不传输的内容**：我们不会在本应用内向任何服务器上传你的本地文件、账户令牌、游戏存档、日志（除非你主动导出并自行分享），也不会进行后台静默传输。

6.5 **你的控制手段**：可在系统层限制本应用联网（Android 设置 → 应用 → ACL-PE → 流量/网络），或在应用内保持"仅 Wi-Fi 下载"。限制联网会使依赖网络的功能（下载/搜索/登录）不可用，但不影响已就绪环境下的本地功能。

7.2 **历史版本**：本应用的开源仓库会保留本政策的修订历史（提交记录），你可对照查看变更内容。

7.3 **你的权利**：基于本应用"数据全在本地、我们不持有你的数据"的设计，你在事实上已经拥有对信息的**完整控制权**（访问、更正、删除、导出、限制处理、撤回同意）。若你所在司法辖区规定了额外权利（如 GDPR/CCPA 项下的权利），你可以通过本政策末尾的联系方式向我们主张；由于我们不持有你的个人数据，我们通常会指导你如何在设备上直接行使这些权利（例如清除数据、删除特定文件）。

7.4 **儿童隐私**：本应用不面向 13 周岁以下儿童单独设计，也不会有意收集儿童个人信息（我们本就不收集个人信息）。若你是未成年人的监护人，并认为相关数据需要处理，请联系我们。

8.1 我们采取的技术措施包括但不限于：应用私有目录存储、Android 沙箱隔离、令牌加密（Android Keystore + AES-GCM）、日志脱敏、下载物哈希校验（SHA-1/SHA-256）、tar/zip 解压路径穿越防护、默认禁用明文传输。
